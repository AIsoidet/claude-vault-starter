# Метрика: активный пользователь

Активный = совершил хотя бы одно **ключевое действие** за период. Просто открыть приложение не считается.

## Детали

Ключевые действия (`events.event_name`):
- `product_view` — открыл карточку товара
- `add_to_cart`
- `order_created`

Не считаются: `app_open`, `push_open`, `screen_view` главной.
Тестовые аккаунты исключаются всегда, правило — в [[notes/таблица-orders]].

```sql
SELECT count(DISTINCT user_id) AS dau
FROM events
WHERE event_date = today() - 1
  AND event_name IN ('product_view', 'add_to_cart', 'order_created')
  AND user_id NOT LIKE 'test_%'
```

Почему так: по `app_open` DAU завышался на ~30% из-за пушей, которые открывают приложение без намерения купить.
Решение продуктовой команды от 20.10.2026.
