description: Разобрать inbox/ — разложить сырое по заметкам, обновить оглавление и журнал
---
Разбери все файлы в `inbox/` по правилам из `AGENTS.md`.

Для каждого файла:
1. Прочитай `index.md` и пойми, есть ли уже заметка на эту тему.
2. Есть — дополни её. Нет — создай `notes/тема.md` по формату из `AGENTS.md`.
3. Факты, которые уже живут в другой заметке, не копируй — поставь ссылку `[[...]]`.
4. **Сверь с базой.** Если новое противоречит тому, что уже записано (определения, цифры, решения),
   не перезаписывай. Вынеси в ответ отдельным пунктом «⚠️ Противоречие» с обеими версиями.
5. Задачи и сроки собери в `notes/задачи.md` (создай, если нет): `- [ ] что — срок — откуда`; срока нет — не выдумывай, пиши без него.
6. Если в inbox ссылаются на файл из `sources/` — открой его и проверь, а не пересказывай догадку.
7. Обработанный файл inbox перенеси в `archive/inbox/` (не удаляй: так ничего не теряется и без git).

В конце:
- обнови `index.md` — по строке на каждую новую заметку; подходящего раздела нет — заведи новый;
- допиши в `log.md` строку `[дата] inbox | что разобрано → куда`;
- дай мне короткий отчёт: что куда легло, противоречия, вопросы ко мне.
