Проверь базу. Ничего не исправляй сам — сначала отчёт, правки только после моего «да».

Проверь:
1. **Противоречия** — один и тот же факт с разными значениями в разных заметках.
2. **Устаревшее** — заметки с `updated` старше 3 месяцев, где есть сроки, статусы, цены.
3. **Битые ссылки** — `[[...]]` на несуществующие файлы.
4. **Сироты** — заметки, которых нет в `index.md`.
5. **Раздутые файлы** — заметки длиннее 300 строк, абзацы длиннее 400 символов, `AGENTS.md` длиннее 120 строк.
6. **Копии вместо ссылок** — один и тот же абзац или определение в двух местах.
7. **Inbox** — что лежит дольше недели.

Отчёт: таблица «что / где / что предлагаю». В конце — одна строка в `log.md`: `[дата] lint | найдено N`.
